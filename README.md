# personalweb

个人项目合集，包含个人主页与医疗随访相关的业务分析资料。

## 项目简介

本仓库包含两部分内容：

1. **个人主页**（`index.html`）：个人介绍页面，同时附带开源合规与许可证说明文档。
2. **出院随访与患者协作业务分析**（`docs/` 目录）：围绕"清禾综合医院门诊之后的随访"场景，整理的业务挖掘与现场调研资料，包括：
   - `出院随访与患者协作-业务挖掘报告.md`
   - `出院随访与患者协作-现场调研报告.md`
   - `访谈记录-report.md`
   - `技术方案.md` / `技术方案.docx`
   - `流程图.md`
   - `提示词.md`
   - `清禾综合医院-门诊之后，随访之前-四份可核对资料.html`
