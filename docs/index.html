系统定位

面向骨科常规术后出院随访的「安排与记录辅助」智能体系统：只读数据条件下生成排程建议与结构化记录初稿；诊疗判断、记录覆盖、责任转移与对外承诺均由具名人工确认后生效。

⚠ 合成训练案例。HIS 仅只读（f32）、AI 不诊断/调药/代签（f22）、危险信号立即升级（f11）。这些都是代码里的确定性硬卡，不是提示词建议。

统一返回结构（core.py）

成功：{"ok": true, "data": {...}, "error": null}
失败：{"ok": false, "data": null, "error": {"code": "REDFLAG_HIT", "msg": "命中危险信号：呼吸困难；已停止问卷并冻结任务"}}
业务失败统一 HTTP 200 + ok=false（任务/患者不存在用 404），调用方只看 error.code 判断业务成败。
